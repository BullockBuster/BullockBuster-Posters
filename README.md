## About BullockBuster

BullockBuster is a curated collection of custom poster artwork created for Plex collections and personal media libraries.

Each design begins with my own concept and visual direction, then develops through iterative AI generation, prompting, revisions, comparison, selection, and final curation. Only finished artwork that I would personally use is included in the main collection.

## Repository Structure

```text
BullockBuster-Posters/
|-- posters/             Final selected collection posters
|-- alternates/          Additional approved variations
|-- overlays/            Downloadable overlay graphics
`-- assets/
    `-- branding/        BullockBuster branding and README visuals
```

## Downloading Artwork

### Download One Poster

1. Open the `posters` or `alternates` folder.
2. Select the poster you want.
3. Open the full image.
4. Click **Download raw file** in the upper right corner.

### Download the Complete Collection

Use the **Download the Complete Collection** link near the top of this page, or download **BullockBuster-Collection-Posters.zip** from the [latest release](https://github.com/BullockBuster/BullockBuster-Posters/releases/latest).

The named ZIP is the recommended complete download and includes the final posters, alternate designs, overlays, and project branding.

## Using a Poster in Plex

1. Open the desired collection in Plex.
2. Select the pencil icon to edit the collection.
3. Open the **Poster** section.
4. Choose or drag in the downloaded PNG.
5. Save your changes.

The reusable [Direct From Disc Overlay](./overlays/Direct%20From%20Disc%20Overlay.png) provides a polished way to identify titles sourced directly from your own physical media.

It can be applied manually or incorporated into automation tools such as Kometa. Because positioning and overlay configurations vary between libraries, a prebuilt Kometa configuration is not currently included.

An optional matching [Direct From Disc Collection Poster](./posters/Direct%20From%20Disc%20Collection%20Poster.png) is also included.
