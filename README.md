\## About BullockBuster



BullockBuster is a curated collection of custom poster artwork created for Plex collections and personal media libraries.



Each design begins with my own concept and visual direction, then develops through iterative AI generation, prompting, revisions, comparison, selection, and final curation. Only finished artwork that I would personally use is included in the main collection.



\## Repository Structure



```text

BullockBuster-Posters/

├── posters/             Final selected collection posters

├── alternates/          Additional approved variations

├── overlays/            Downloadable overlay graphics

└── assets/

&#x20;   └── branding/        BullockBuster project branding

```



\## Downloading Artwork



\### Download One Poster



1\. Open the `posters` or `alternates` folder.

2\. Select the poster you want.

3\. Open the full image.

4\. Click \*\*Download raw file\*\* in the upper right corner.



\### Download the Complete Collection



Use the \*\*Download Everything\*\* link above or select:



\*\*Code → Download ZIP\*\*



This downloads the complete repository, including final posters, alternate designs, overlays, and project branding.



\## Using a Poster in Plex



1\. Open the desired collection in Plex.

2\. Select the pencil icon to edit the collection.

3\. Open the \*\*Poster\*\* section.

4\. Choose or drag in the downloaded PNG.

5\. Save your changes.



\## File Naming



Final selections follow this format:



```text

Movie or Franchise Name Collection Poster.png

```



Alternate designs follow this format:



```text

Movie or Franchise Name Collection Poster - Alternate 1.png

```



The poster without an alternate number is always the primary selected version.



\## Artwork Process



The artwork in this repository is AI generated from original concepts and visual direction, followed by manual iteration, refinement, comparison, naming, selection, and curation.



Multiple versions may be explored before a final design is selected. Rejected drafts are not included.
